## OpenSpec and Superpowers routing

Use the v2 bridge contract and map native skill names explicitly. Before apply,
run `bridge_guard.py preflight` with explicit repository, base and change in an
authorized workspace. Missing artifacts STOP. Record RED/GREEN and independent
review against the candidate. Run `verify` after recording mandatory results.
Guard success is not proof of those results. Workspace creation, archive, PR,
push, merge and human acceptance are separate authorized actions, not automatic.
